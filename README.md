# 八拍 · Choreo Studio

把音乐、八拍和动作放在一个简单的工作台里。当前先完善经典手动编辑器，使用 React、TypeScript、Three.js 与 Cloudflare Workers；v2.1 的真实教学闭环保留独立验收。

**当前版本：version 11 经典手动编辑器，已实现并上线。** 2026-10-08 用户明确 AI 暂不接入，优先本机编辑效率、可靠音频和作品保护。首次使用和新场景默认手动 K帧，已有场景恢复保存的模式；舞台快捷键、音乐异步取消/旧结果隔离和原选段起点恢复已可用。本轮新增原创实体成人 mannequin，以及数值、滑条、3D 操作环和新写 K 共用的关节活动包络；旧作品的权威动作保留。[功能源码](https://github.com/DFerryman/ChoreographyStudio/commit/e02b76bab054120b31314622cf416d752e847b6f)已 push 到 `main`，Cloudflare v11 `f245eba5-7cda-4950-bda7-f0cae576368b` 已部署。161 项本地基础检查、4 项新增约束交互和 20 项既有相关交互通过；CI 与公网的实际结果见 [验证记录](docs/VERIFICATION.md)，运行版本见 [部署记录](docs/DEPLOYMENT.md)。

界面采用少量必要按钮和清楚层级：舞台工具、播放/时间定位和写 K 常用操作保持可见，姿态复用、删除/重置、键时刻转移、相机高级选项、坐标与备份按需展开。折叠只整理入口，保留数据与草稿、冲突、未保存和错误保护；后续新功能先决定入口层级。

实体人体、骨架、动作与节奏样例均为原创程序生成；未使用 UE 官方或其他第三方模型资产。模板与手 K 不调用生成模型。真实舞蹈动作、外部生产 Avatar 与正式教学 MP4 尚未接入；教师与生产服务仍独立验收。原工程 ZIP 是生产契约接入的独立依赖，不阻塞当前手动编辑；`preview-1` 不冒充原工程包 2.1.0 契约。完成阶段须提交并 push 到 `DFerryman/ChoreographyStudio` 的 `main`，同步授权 Cloudflare 预览并核对实际运行版本，验证文档也须提交。

## v11 操作说明

首次使用或新建场景直接进入「手动 K帧」；打开旧场景按其原有模式和工具恢复，不重烘焙动作或清空音乐。选中关节，用舞台旋转环或数值摆姿，再显式写 K；「移动角色」操作整个 Root，6 个末端关节仍只读。

先点击或用 Tab 聚焦舞台，可用 `←` / `→` 逐帧、`Space` 播放/暂停、`K` 写当前关节、`Delete` 删除当前关节 K；整体移动工具下 K/Delete 只处理 Root。`Ctrl` / `Cmd` + `Z` 撤销，配合 `Shift` 重做，也支持 `Ctrl` + `Y`。输入框、按钮和对话框保留自身键盘行为；写帧与删除沿用草稿、只读轨和观看保护，播放中仅响应播放/暂停。

音乐设置关闭或取消时停止待处理解码与试听，暂停或离开播放时取消尚未完成的启动；迟到的异步回调不能恢复旧播放或覆盖新设置。重开音乐设置恢复已确认的原八拍起点，确认前不改变作品。姿态复用、删除/重置、键时刻调整、相机和备份通过对应展开入口使用：属性栏的「姿态复用」「更多编辑操作」「键盘快捷键」，时间线的「移动与复制关键帧」，以及「相机选项」「舞台信息」「播放选项」「关节信息」「场景备份」。

新增旋转按关节限位，并检查组合后的四元数 swing/twist；肘沿局部 X 的 −145°～0° 屈曲，膝为 0°～145°，左右肩/髋的外展 Z 方向相反。具体范围见 [活动限制表](docs/MANUAL_EDITOR.md#原创人体与关节活动限制)。旧超限姿态仍可原样观看、保存和恢复；调整或写入该关节时才应用限制，「K 完整姿态」会对本帧 19 个可编辑旋转应用限制并明确写入。Root 编辑不修正其他旧旋转。

IK、脚锁、穿地/身体碰撞、质心支撑与重力/动力预览仍是后续工作，路线见 [真实编舞体验评估](docs/REALISM_PLAN.md)。当前限位不保证整段插值或动作符合完整人体物理，也不构成舞蹈/教学审核。

## 这版可以操作什么

工作台以实体人体舞台、上下文属性和时间线为中心；手动 K帧为默认模式，八拍编排与本地模板替换可按需切换。桌面与手机使用同一套草稿、提交和保存规则。

1. 打开原创 120 BPM 示例，用实体成人 mannequin 查看 32 秒、8 个八拍的组合；小节点辅助仍对应原 25 关节，可直接拾取。
2. 在手动模式选中关节、摆姿并写 K；切到八拍编排后可使用本地模板替换预览，采用、放弃、撤销或重做。
3. 切换正背面、镜像观看、0.5×/0.75×慢放、八拍循环与节拍提示。
4. 读取本地音频，手动设置 BPM、数拍关系和第一数拍；确认完整选段后生成模板初稿。
5. 自由环绕、平移和缩放相机，切换侧面/俯视/正背面并复位；全身取景找回移远角色，选中关节后聚焦近看，也支持只读末端；节点坐标仍为未镜像数据。
6. 新建、打开、保存、复制、重命名和删除多个本机场景；分别保存原音频、编排历史、播放位置、相机与视图设置，刷新后恢复；旧版单项目自动迁移。
7. 下载含原音乐的完整 `.choreo` 场景包，或保留旧 JSON 下载；导入备份并恢复为新本机场景。
8. 在时间线把指定范围的显式 K 复制或移动到目标帧，同轨碰撞须明确确认；撤销/重做与场景保存沿用原流程。

本地音乐不发送服务器。每个设备/浏览器独立保存；清理浏览器数据会删除本机项目。旧 JSON 不包含原音乐；v10 已提供完整包与旧 JSON 恢复，操作见下节。

3D 场景使用右手系、Y 向上、+Z 为角色正面、米单位和 XZ 地面；镜像仅改变观看，节点选择和相机操作不修改动作。P1 不包含 IK、骨长编辑、云保存、真实动作或教学 MP4。

v9 的取景范围以当前可见骨架为准，包括未写 K 的草稿、镜像、候选和教学观看。全身取景按舞台实际宽高比留出边缘，聚焦关节也支持只读末端；没有动作或没有选中关节时给出相应禁用状态。点击取景不暂停播放、不跳帧、不写 K，不切换原稿/候选或清空草稿；相机随本机场景保存。它是一次明确操作，跳帧或调整窗口后不自动再次取景。

## P1 手 K 操作范围

确认音乐数拍并生成初稿后，点击人体上的辅助节点或在属性栏选中关节，再点舞台「旋转」，即可进入暂停、未镜像的手动编辑并显示局部旋转环。「选择」「旋转」「移动（整体）」是舞台的三个常用工具；整体移动显示世界空间 XYZ 箭头，移动整个角色的 Root，保留骨长。6 个末端节点只供选择/观察，可通过整体移动改变角色位置。

旋转和位移均可直接在舞台拖动，或点「数值与写 K」进入对应数值组。在「更多编辑操作」中可点击「从站姿开始」，确认后在同一场景建立站姿基底。播放时点编辑工具会暂停在实际音频位置并对齐帧；镜像观看会切回原始姿态，候选预览会明确切回原稿编辑。

草稿先显示在舞台，同一帧切换选择/旋转/移动工具或关节会保留草稿；点击写入当前关节、Root 或完整姿态后才改变动画。跳帧、播放、切换编辑模式或保存前，未写草稿会要求写入、放弃或取消。撤销/重做与编排共用场景历史，正式轨道、原音频、相机和工具设置随场景保存恢复。

v7 本轮补充轨道状态与单轨删除 UI：删除当前关节只处理选中旋转轨，删除 Root 只处理位置轨，「删除当前帧关键帧」仍明确处理该帧所有轨。不存在显式键时禁用删除，不生成空历史。时间线可筛选全部、当前关节或 Root，筛选只改变观看，不修改动画或保存格式。跳 K 只找严格在当前帧之前/之后的显式键，不把基底端点当作已写键；未选关节、只读末端和空轨各有相应提示。本轮已完成验证并上线，具体证据见验证和部署记录。

时长由已确认 CountMap 固定，键以 30 fps 定位并保留精确末帧。关节在相邻锚间 SLERP，Root 线性插值，影响整段相邻键区间。采用模板替换时会提示固化当前动画并清除可编辑轨，撤销可恢复；它不会将旧轨重新套到新基底。实际版本与检查见部署和验证记录。

## v10：备份恢复与调整 K 时刻

展开底部「场景备份」，点击「下载完整场景包」得到 `.choreo`，包含原音乐、正式动画、历史与相机；v11 将备份操作收进按需展开的入口。已有草稿先选择写入、放弃或取消。恢复时打开「场景 → 导入场景备份」，选择文件和名称，再点「作为新场景导入」。程序在浏览器校验音乐和数据，事务保存成功后才打开新场景；已有场景保留。原「下载项目备份」仍下载不含音乐的 JSON，恢复时需重新关联原音乐，仅能核对时长，用户须确认是同一曲目。格式、资源限制及兼容规则见 [场景备份说明](docs/SCENE_BACKUPS.md)。

若打开的本机场景显示「原音乐缺失」，点击「恢复原音乐」并重新关联备份时的原曲，验证后恢复为新场景。原编舞、数拍、历史和相机保留；已有草稿仍可明确选择写 K 后继续，恢复将包含最新正式 K。缺音乐期间不播放、不保存或导出完整包，仍可下载项目 JSON；程序不会悄然配入示例音乐，也不会通过重新导入音乐重建编舞。此分支已通过相关本地复核及本轮线上流程。

在「手动 K帧」时间线选择全部、当前关节或 Root 范围，停在已有显式 K 的源帧，展开「移动与复制关键帧」并输入「目标帧」，点「复制到目标帧」或「移动到目标帧」。移动移除源键，复制保留源键；目标同轨已有 K 时须确认替换，其他轨保留。草稿沿用现有处理，成功可撤销/重做并随场景保存；相邻区间插值可能改变，音乐和场景时长保持原样。它处理已写键，不复制插值姿态或隐式端点。

对话框支持 Tab/Shift+Tab 环绕、Escape 取消最上层并恢复合适焦点；改名输入继续自动聚焦。取消不代替写 K、删除或采用；忙碌操作保留既有保护。这些 v10 功能已完成相关本地、必要单轮线上及实际源码 CI 验收并上线；最终文档提交与同版部署收据由部署记录追踪。

## Cloudflare 部署

当前线上使用同一份 Web 构建与 API，通过可复现的 inline gzip 后备模块发布；Cloudflare 记录为 `has_assets=false`。生成工具为 `infra/prepare-inline-preview.mjs`，实际部署 ID、验证及再现步骤见部署记录。音乐仍只在浏览器本地处理。

`/api/*` 按客户端 IP 配置 20 次 / 60 秒原生限频；超限 429，保护缺失或失败 503。实际 Worker 没有 D1/KV/DO 绑定，本项目不写 D1。限频按节点生效且最终一致，共享 IP 会共用额度；429 与当前 inline 静态交付仍计 Worker 请求，因此它不是账户全局费用硬上限。本机编辑和保存不调用业务 API；后续服务写入还需幂等、合并写入和日预算门槛。

`wrangler.jsonc` 配置的 Workers Static Assets 是标准部署路径，后续恢复官方资产上传后使用。已认证的 Wrangler 环境运行：

```sh
npm run deploy
```

认证只在执行环境配置，不写入源码或配置文件。GitHub Actions 自动检查构建、契约与交互；main 的纯 Markdown 更新不重复运行整套检查，PR 检查保持启用。目前未配置含部署凭据的自动发布。可通过 Cloudflare Workers Builds 连接本仓库，设置构建命令 `npm run build`、部署命令 `npx wrangler deploy`，完成之后再记录启用状态。

Python 动作处理和 FFmpeg 不在普通 Worker 中运行。后续按真实负载选择独立执行环境，保留 PostgreSQL 与私有对象存储的方案。
