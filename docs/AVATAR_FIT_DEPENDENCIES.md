# Offline avatar fitting dependencies

The reusable fitter uses NumPy 2.3.5 and SciPy 1.17.0 (BSD-3-Clause) in Python 3.11 or later. The current run used Python 3.12.14. Pin versions with `infra/requirements-avatar-fit.txt` when regenerating. NumPy/SciPy and their binary dependencies are used offline and are not shipped in the Web application. SciPy `spatial.ConvexHull` calls Qhull; distribute its license and the dependency wheel license notices if distributing those binaries.

The existing Quaternius asset remains CC0, the repository retains its MIT license, and runtime collision uses the existing Apache-2.0 Rapier dependency. No license text or frozen asset README is changed.
