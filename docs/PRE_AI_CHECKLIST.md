# AI 接入前本机工作台清单

此清单跟踪可独立完成的本机编辑闭环。当前线上最新已验证功能为 v9 相机取景，实际本地/必要线上/源码 CI、push 和部署均通过。v10 已实现下述 pre-AI 补齐，107 项基础检查、最终构建/Worker 类型与 dry run、8 个不同本地范围经首轮/手机定向复核及新增缺音乐恢复相关单项通过。首次隐藏状态脚本断言、未匹配测试的 grep 尝试、测试前沙箱启动失败与恢复保留；10 份实际浏览器诊断的错误、警告与业务 API 请求均为零。公网/实际源码 CI 与发布尚未完成。实际结果由 VERIFICATION.md / DEPLOYMENT.md 更新，代码存在不等于交付。

备份不得夹带姿态剪贴板、候选预览缓存、未提交草稿或凭据。导入不是重新生成：精确 Take、不可变基底、显式采样时刻、手 K 轨、CountMap、原音频和相机不能由 plan 重烘焙替换。文件、音频、历史和所有动作样本的累计资源必须有限，不能只限制单个轨或单个 Take。

## 完成本轮后仍须独立开展的工作

- 原工程 2.1.0 ZIP 仍需获得授权文件，在私有工作区先读根指令并执行原验证，再导入同源生成契约；当前 `preview-1` 不声称生产兼容。
- 真实动作/Avatar、音乐使用许可、独立舞蹈审核和教师安排需要可检查的材料；原创程序化骨架的交互测试不替代这些证据。
- Python 动作处理与 FFmpeg 需要真实可运行的执行环境和同版产物。当前 Motion Worker 目录仅为接入计划；没有正式教学 MP4。
- AI 服务必须在明确结果契约、失败/取消/旧版本保护、身份/权限、幂等及费用预算后接入。当前预览不调用模型，也不接受服务器音乐/项目写入。
- 设备帧率、实际音频输出延迟、最终 MP4 音画和教师对照需要真实测试。浏览器 smoke 或数学插值通过不能宣布教学质量验收通过。

**M0–M3 继续未通过。** 上述本机完善不解除原素材、契约、生产服务和教师门槛。

## 验证和交付约束

相关数学、解析和存储检查优先本地；浏览器测试使用原创音频与程序化骨架。每次有意义的阶段只做必要单轮线上验证，复用未变化范围的有效证据，不做公网高频循环、压测或服务写入探测。

所有本机编辑、备份恢复、相机和模态操作均不得新增业务 API 调用、D1 写入或自动云保存。沿用实际原生 API 限频；它不是账户总费用硬上限。完成源码与文档修改必须 commit/push 到 `DFerryman/ChoreographyStudio`，并同步授权 Cloudflare 预览，核对实际提交、版本和资产后才记录交付。
