## 完成本轮后仍须独立开展的工作

- 原工程 2.1.0 ZIP 仍需获得授权文件，在私有工作区先读根指令并执行原验证，再导入同源生成契约；这是原契约接入的依赖，不阻塞当前已授权的经典手动编辑完善，`preview-1` 不声称生产兼容。
- 真实动作/Avatar、音乐使用许可、独立舞蹈审核和教师安排需要可检查的材料；原创程序化骨架的交互测试不替代这些证据。
- Python 动作处理与 FFmpeg 需要真实可运行的执行环境和同版产物。当前 Motion Worker 目录仅为接入计划；没有正式教学 MP4。
- Workers AI 已按最新授权接入有限编排请求；本轮禁止真实推理验证，因此真实模型输出质量仍未验收。生产身份/权限、租户、持久任务/幂等和账户级费用硬门槛继续独立建设；当前不接受服务器音乐/项目写入。
- 本机事务失败保护已验收，但浏览器容量由设备/浏览器决定，清理会删除本机数据；生产云存储容量、账号隔离、服务端日写入预算和费用硬门槛仍需实际实现与验证。原生 API 限频不等于账户级费用上限。
- 设备帧率、实际音频输出延迟、最终 MP4 音画和教师对照需要真实测试。浏览器 smoke 或数学插值通过不能宣布教学质量验收通过。

**M0–M3 继续未通过。** 上述本机完善不解除原素材、契约、生产服务和教师门槛。

## 验证和交付约束

相关数学、解析和存储检查优先本地；浏览器测试使用原创音频与程序化骨架。AI binding/浏览器请求一律 mock，部署验证只核对配置及不进入推理的路径，不实际调用模型；取消后的供应商侧计算也不能被声称已经停止。每次有意义的阶段只做必要单轮线上验证，复用未变化范围的有效证据，不做公网高频循环、压测或服务写入探测。

本机编辑、IK、脚锁、物理预览、备份恢复、相机和模态操作不调用业务 API、不写 D1 或自动云保存；显式 AI 请求是授权例外。沿用实际原生 API 限频与 AI 专属请求限频，它们不是账户总费用硬上限。完成源码与文档修改必须 commit/push 到 `DFerryman/ChoreographyStudio`，同步 Cloudflare 并核对提交、版本/绑定和资产后才记录交付；新增需求同期同步 Notion。
