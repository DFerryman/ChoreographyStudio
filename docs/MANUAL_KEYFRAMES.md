# P1 手动关键帧规则

在原创合成骨架上实现本机手 K。此设计是 `preview-1` 的编辑扩展，不等于 original 2.1.0 的已验证协议；不包含 IK、骨长修改、真实动作质量复检或教学 MP4。v5 初版和 v6 操作入口已验证交付；下述轨道状态、单轨删除与跳 K 已在 v7 实现并上线，实际通过和发布证据见验证、部署记录。

## 操作和空间

一个场景的已确认 CountMap 决定完整动作时长，不拖动或裁剪音乐/八拍。编辑时间用动作内相对时间，以 30 fps 的整数帧定位。最后一帧为 `ceil(duration × 30)`，其时间固定为精确结束时刻；不能把短末帧扩到音乐范围外。

19 个具有可见方向或子骨骼的节点可编辑父相对局部旋转。6 个手指尖、脚尖、脚跟末端节点保留选中和坐标观察，不编辑其不可见旋转。Root 平移独立于 Hips 旋转；骨长、父子层级和静态局部偏移不变。空间继续采用右手系、Y 向上、人物 +Z 向前、XZ 地面和米单位。

数值输入为 intrinsic XYZ 欧拉角（度，每轴 −180 至 180）；持久化为归一化 XYZW 四元数。Root 数值为世界位置，X/Z 在 −5 至 5 米、Y 在 0 至 3 米，仅是本轮场景操作范围，不是人体关节或接触质量约束。

选中关节仅做选择，不自动进入编辑或改变动画。默认八拍编排中，选中后也须在附近提供「旋转关节」「移动角色」入口；舞台工具栏持续提供选择、旋转、整体移动，以及到数值与写 K 的明确入口。手机点击编辑工具后保留舞台位置，用户主动选择「数值与写 K」才滚动到对应数值组。

视口操作环在未镜像、暂停的编辑模式下围绕选中关节，以 local 空间旋转；整体移动将 TransformControls 绑定 Root，以 world 空间 XYZ 箭头移动整个角色，不平移单个关节或改变骨长。拖动操作柄暂停相机操作，空白处仍可导航相机。Root 拖动与数值使用同样范围：X/Z ±5 米、Y 0–3 米。

显式点击旋转或整体移动工具可以进入编辑：播放中须读取实际音频时间后暂停并对齐当前帧；镜像须返回未镜像姿态；候选/教学观看须明确返回原稿。候选动作不能被写为草稿或无提示采用。尚无动作时禁用工具并给出生成初稿提示；末端节点禁用旋转并说明只读，仍允许整体移动。镜像仅用于观察，不从镜像空间写入动作。

工具/场景切换或取消拖动时须清理 capture、活动指针与选点起点，恢复相机和下一次选择/操作柄拖动。操作柄被第二触点打断时，隔离该组触点直到全部抬起，不让第二触点驱动原生操作柄；随后正常双指相机手势仍可用。

## 草稿、提交与历史

滑条、数值或操作柄先改变当前帧的完整 Pose 草稿，舞台即时预览。切换同一帧的选中关节或选择/旋转/整体移动工具可继续摆姿态，不写 K、不增加历史。选择工具隐藏操作柄，但保留手动模式和当前草稿；实际离开手动编辑模式仍须处理草稿。镜像观看期间草稿只读，再次显式点击编辑工具可返回未镜像姿态继续编辑同帧草稿。草稿不能被当成已写入的关键帧、权威动画或已保存场景。

用户显式写入当前关节、Root 位移或完整姿态。同轨同帧写入为更新，不产生重复键；完整姿态一次写入 19 个旋转和 Root，成为一个撤销条目。关节和 Root 分别显示当前帧是否有显式 K，不能以插值姿态或尚未写入的草稿冒充键。v7 将 core 的单轨删除接入 UI：分别删除当前关节旋转键、Root 位移键，保留「删除当前帧关键帧」并明确说明移除本帧全部轨的全轨操作；单轨删除不得删除同帧其他轨。

删除请求先固定其种类、关节和帧，再处理未写草稿；确认后继续执行原目标，不能因弹窗期间的选择或时间变化改删其他键。目标无显式键时不提交、不重烘焙、不增加 revision 或撤销条目。每次真实的正式动作修改生成新动画 ID、增加作品 revision，并清空旧版本的预览确认；旧候选不可覆盖新动作。

跳帧、播放、切换场景/编辑模式、撤销、改音乐或生成模板前，未写入草稿须明确选择写入后继续、放弃或取消。场景保存也经过这一处理；存储事务失败不显示保存成功，当前修改仍可继续编辑。

沿用每场景 12 步历史，不另建与编排分离的撤销栈。相机、镜像、关节选择不修改权威动画，也不触发重新烘焙。

## 轨道查看与跳 K

编辑器的上一个/下一个 K 在全部轨的显式键时刻中查找严格早于/晚于当前帧的相邻键；不会反复跳到当前键，也不会把未写入的 0 帧或结束基底锚作为 K。没有对应方向的键时禁用按钮，原逐帧和秒输入继续可用。

时间线提供全部、当前关节和 Root 三种查看范围。标记、列表、键时刻数量及时间线跳 K 均取自当前范围的显式键；全部轨同帧的键合并为一个时刻，当前关节和 Root 只显示各自轨。未选关节时说明需要先选择，6 个只读末端说明没有可编辑旋转轨，空轨明确显示没有显式 K；不能回退显示其他轨而让用户误判。

筛选是临时观看状态，不改变 take、revision、历史或保存契约，不加入 `viewer` 持久化。筛选本身不处理或提交草稿；通过上一/下一 K、时间线标记或列表跳帧仍复用现有未写草稿的写入、放弃、取消确认，不直接绕过保护。

## 动画数据与插值

每个 Snapshot 可选保存 `manual: KeyframeSequence`，包含 `schema: manual-keyframes-1`、固定 `fps: 30`、不可变 `baseTake`、按关节的稀疏旋转轨和独立 Root 位置轨。键记录整数 frame；输出仍为 `BakedTake`，播放、观察和 JSON 备份消费同一权威产物。

有显式键的轨以基底在 0 和精确结束时刻的姿态作为隐式端点，用户写入端点时替代该端点。相邻旋转键最短路径 SLERP，相邻 Root 键线性插值；这会影响相邻键之间的整段该轨，不宣称只改当前帧或选中八拍。未编辑轨继续使用原基底样本。删除最后一个显式键后，该轨回到基底；全部键删除后保留原始 poses/times，只生成新的动画版本。

烘焙保留基底的显式时间数组、八拍边界与精确末样本，同时加入显式键时刻。不能由 plan 再次生成 base，也不能把已编辑输出不断叠成旧轨的新基底。有限数、合法节点、整数帧、非零四元数、资源边界必须在编辑入口校验；整个序列最多 4096 个轨键，输入与输出都最多 6001 个显式样本，超限明确拒绝。

“从站姿开始”在同一音乐/CountMap/场景下建立中立原始姿态，方便用户构建自己的序列；清空已有手 K 的操作可撤销。模板重新生成清空手 K；采用八拍替换直接消费候选的权威 take，将当前可见动画固化为下一次编辑的基底、清空旧可编辑轨，须明确提示且可撤销。范围外不变仍按替换的权威动画检查，不能保留旧轨再次覆盖新基底。

## 保存与兼容

编辑序列、基底、权威 take 与历史作为 SceneDocument.project 一起由 IndexedDB 事务保存，原音频仍单独包含在同场景。viewer 可选保存 editorMode 和 transformTool（select/rotate/translate）；旧 `choreo-scene-1` 没有工具字段时，手动模式默认旋转、编排模式默认选择。旧 Scene 无 editorMode 或 Snapshot 无 manual 时按已有动作恢复，不重烘焙旧 plan，不替换原音频。恢复工具是视图恢复，不是动画提交。

音乐或 CountMap 发生改变时旧手 K 不自动套到新时长。JSON 备份包含正式编辑序列与权威结果，未提交草稿不假装保存成功；JSON 当前尚无导入 UI，原音乐需另行保留。

编辑、播放、烘焙、轨道筛选和保存均在浏览器本机运行，无业务 API 调用、自动云保存或 D1 写入。v7 不修改 core、API、基础设施或已有数据契约，也不增加姿态复制、IK 或自由音乐时间线。验收优先本地数学/交互测试，覆盖单轨删除不伤其他轨、空删除不写历史、撤销/重做、严格跳键、范围筛选、草稿保护和小屏操作；正式部署只做一次必要的公网流程验证，继续保留已配置的原生 API 限频。
