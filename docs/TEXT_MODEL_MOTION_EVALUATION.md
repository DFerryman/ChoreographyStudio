## 实际生成来源与自有原稿

三份输出的来源为 **`codex-session / gpt-6.1-sol`**，由本次 Codex 会话中的文本模型创作同时变化的全身数值关键姿态，再由本地可信适配器绑定冻结请求。没有调用 Cloudflare 或其他外部推理 API，也没有读取 catalog、旧真人动捕片段、用户场景或私人音频。它们不是现有街舞／Salsa 素材的截取、变速或重定向。

本地 Python 负责序列化作者提供的姿态行、继承未改关节的零旋转／放松手臂姿态，并用简单膝角三角近似估计 Root 高度。该近似不是 IK 或接触解算；模型没有生成区间首末、外部动作和边界速度，这些由既有程序冻结。末端 marker 保持零旋转，不能宣称已生成独立手指编舞。

芭蕾原始检查记录 **180 个地面违规**，最大穿入 **19.628157 mm**。已有 Root 调理在区间内改变高度，首末整个 knot 和关节曲线均不变；最密已有诊断测得最大 Root 改变量 25.668757526 mm。最终独立调用使用 `correct:false`，三份均为完整覆盖、零违规；最终检查的 corrections 为空，并不抹去芭蕾此前的 Root 修订。`acos(dot)` 差异报告中的约 5.96e−8 rad 是近零舍入，逐分量核对没有真实关节修正。

检查范围仍为有限自适应 Quaternius 身体／实际足部代理、骨架功能包络、插值与单侧 SO(3) 曲率、汇总接触力及摩擦，`articulatedDynamics=false`。工程 accepted 不证明连续时间无碰撞、完整关节动力学、连续蒙皮、人体力量、临床关节范围或舞种质量；采样速度与脚部 marker 轨迹也不能自动当作脚滑／稳定接触认证。
