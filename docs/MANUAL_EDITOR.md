| LeftShoulder／左锁骨 | −20～20 | −20～20 | −10～30 | Y 轴 twist；swing ≤35 |
| RightShoulder／右锁骨 | −20～20 | −20～20 | −30～10 | Y 轴 twist；swing ≤35 |
| LeftUpperArm／左肩 | −120～45 | −65～65 | −15～150 | Y 轴 twist；swing ≤150 |
| RightUpperArm／右肩 | −120～45 | −65～65 | −150～15 | Y 轴 twist；swing ≤150 |

| 左右 Hand／腕 | −60～60 | −15～15 | −25～25 | Y 轴 twist；swing ≤65 |
| LeftUpperLeg／左髋 | −110～25 | −35～35 | −20～45 | Y 轴 twist；swing ≤110 |
| RightUpperLeg／右髋 | −110～25 | −35～35 | −45～20 | Y 轴 twist；swing ≤110 |

| RightFoot／右踝 | −20～40 | −12～12 | −25～15 | Y 轴 twist；swing ≤45 |

球形关节的四元数 Y 轴 twist 取表中的 Y 范围，swing 指离开纵向静止轴的总摆角；三个 Euler 数值各自合法，组合仍可能超限。肘和膝分解后的次级 swing 角分量分别满足 `(Y/8)² + (Z/5)² ≤1` 与 `(Y/4)² + (Z/3)² ≤1`，不是两个可以同时取满的独立范围。四元数 X twist 内部允许肘 −146～1、膝 −1～146，以容纳微小的次级轴组合；表中 Euler 主屈曲边界仍严格。旋转环和 IK 求解中，组合超限时沿向中立姿态的最短 SLERP 弧缩回建议包络，保存的仍是规范化 XYZW 四元数；既有作者创作与写 K 不套用这项投影。左右肘都向 −X 屈曲，左右膝都向 +X 屈曲；左肩/髋外展为 +Z，右侧为 −Z，不随观看镜像翻转数据。

旧作品在加载、采样、播放、保存、导入、删除、键转移和撤销/重做中保持权威数据，不套新表自动修复，也不在重开时重烘焙。旧超限旋转显示原值及提示；Root编辑不重写其他旋转。「K完整姿态」记录当前19个可编辑旋转与Root，6个末端保留；单轨K只记录对应通道。K只做有限值/单位四元数校验与规范化，不再次裁剪老师的姿态。复制/粘贴保留源旋转，形成草稿后仍须显式K。骨长、CountMap、不可变基底与原场景格式保持。

标准限位辅助不保证相邻K的整个SLERP区间或老师创作姿态满足人体包络。v12新增IK、脚锁、接触代理诊断、分段质量/质心和重力候选；v13进一步保护作者K与草稿意图，自动脚锁不能为满足约束改掉明确作者通道，冲突显示真实残差。独立重力/AI候选先预览，明确采用整段替换才改变作品，不在播放或拖动时间线时自动改权威数据。

## version 12：手脚 IK、脚锁与标准人体

手臂和腿使用已安装的 Three.js MIT `CCDIKSolver`，适配当前原生 25 关节骨架。求解只调整目标手/脚对应链，骨长与 Root 不因独立 IK 改变；几何初始化处理直链和膝肘方向，每轮投影共用关节组合限位。拖动舞台平移手柄调整手脚目标；旋转环调整局部旋转，整体移动箭头调整Root。v14取消右侧数值微调，不提供IK目标世界坐标表单。到不了的目标保留位置残差，不伸长骨骼。摆姿先形成草稿，时间轴主按钮或 IK 工具的快捷 K 明确保存完整姿态，撤回、跳帧、保存和候选采用仍走既有保护。

「真实约束」默认折叠。内置 `neutral-adult-v2` 中性成人参数对应当前原创骨架与重绑定的CC0人体皮肤：约 1.85 米、70 kg、重力 9.81 m/s²；16 个对称分段的质量比例合计 1，分段质心和代理几何计算全身质心与惯量。摩擦 0.75、回弹 0.02，并提供有限全身位移/朝向驱动。参数不要求使用者填写，也没有常驻物理参数表单。这是编辑器的近似默认模型，不是个人身体测量或临床标准；其方法依据和限制见 [REALISM_PLAN.md](REALISM_PLAN.md)。

脚底代理按现有实体足部校准：踝局部底面为 Y=−0.082 米，足宽 ±0.048 米，前后范围 Z=−0.075～0.165 米；脚尖/脚跟节点中心不当作脚底。只读反馈显示脚底高度、质量加权质心、穿地与过滤相邻骨段的身体穿插提示。支撑面判据只作为准静态姿态提示，转身、行走等动态动作与飞行不套站姿判据，也不据此拒绝舞步。

从当前帧捕获左/右脚的世界锚点与朝向，到指定结束帧形成有界接触区间。默认三帧平滑进出，普通区间首末帧权重为0；锁从整段动画0帧开始或到最终帧结束时，对应全局边界保留完整权重，不额外淡入或淡出。同脚区间不可重叠，最多32个。锁足烘焙协调腿部 IK，必要时限制 Root 高度以保持固定腿长；不可达的横向目标或脚踝方向不强行扭曲。面板显示当前实际姿态相对锚点的位置/朝向残差及过渡状态，达到与未达到有明确区别。脚锁作为 `manual.footLocks` 的可选版本化数据进入撤销/重做、场景事务和备份；旧场景缺省无脚锁。解除锁定可撤销，采用新候选前明确提示固化当前手 K 与脚锁。

## version 12：重力与 AI 候选

新增支撑脚锁只允许当前脚底在地面接触容差内且没有明显穿地，空中脚需先落地；界面与动作处理均检查该条件。旧已保存脚锁和备份仍按原锚点恢复，不自动改成地面接触。

重力辅助使用 Apache-2.0 的 `@dimforge/rapier3d-compat@0.21.0`，点击「生成重力候选」后才加载 WASM 并模拟。使用一个动态全身代理及跟随作者关节意图的分段碰撞代理，将质量、质心和姿态相关惯量实际交给 Rapier；重力、地面接触、摩擦和落地响应由引擎求解。支撑时位移/朝向驱动有力和扭矩上限，飞行时释放地面驱动并保留弹道重力。它不是每关节独立驱动的全动力学 ragdoll，也不证明作者的每个关节轨迹都满足真实肌肉力矩。

模拟使用 120 Hz 固定步长，从起点独立运行；输出保留全部原显式时刻、30 fps 采样与精确结束时刻，60 秒最多 7200 步，遵守 6001 输出样本上限。模拟可取消，取消/失败不返回部分作品。预览、关闭、采用分开；采用后得到新权威 Take，原手 K/脚锁留在撤销历史中。播放和拖时间线只采样已经生成的 Take，不重新运行模拟、不偷偷修正原稿。

AI 使用 Workers AI 开源 Qwen 模型，通过严格 `ai-arrangement-1` 结果契约，从现有六种原创动作选择顺序和幅度。文字和已确认数拍是唯一输入；原音乐、完整场景与凭据不发给浏览器外的生成服务。结果绑定原场景/CountMap/revision，通过校验和关节限位后先作为候选，明确采用才替换；失败、取消和迟到结果不能覆盖新作品。它是有限动作库编排，并非从文本直接合成任意人体动作。开发与线上检查只使用 mock/拒绝路径，不实际执行推理；真实模型输出质量尚未验收。

## 验收与持续开发优先级

下一步编辑体验的核心是少量关键姿态就能形成自然连续舞步，包括摆腿、换支撑与移动身体时的自动步态/落脚规划。当前 IK、固定接触区间和动态全身代理尚不等于这样的连续动作规划；需要接触相位、摆腿轨迹和身体转移的专门实现与教师观察，不能把单纯 Root 移动或线性/SLERP 插值称为已经自然走动。

本轮验收范围包括快捷键操作、输入/模态隔离、草稿取消与目标固定、单轨边界、首末帧、按键重复、撤销/重做，以及音乐读取取消/旧结果隔离和已有非零八拍起点恢复。检查取消或失败时原作品、音频、CountMap、正式轨及历史保持；成功编辑仍可本机保存、重开和完整备份。界面分层须验证默认常用路径、次要功能展开、错误/保存状态与保护可达性；相关桌面/手机控件、既有按钮和舞台手势不能退化。v11 的已运行结果及 CI/公网证据见 [VERIFICATION.md](VERIFICATION.md)，已发布运行版本见 [DEPLOYMENT.md](DEPLOYMENT.md)；保留首轮失败和修正，不以旧版本证据替代新范围。

v12 验收新增 IK 的真实目标操作/残差/限位/骨长与草稿保护、脚锁区间/解除/历史/重开/备份、静态与动态支撑区别、真实重力/落地与候选采用/取消，以及 Workers AI 的 mock 请求/错误/旧结果隔离。少量 K 的自然连续动作、更多自动接触过渡及教师编舞效率仍需后续专项改进，数学插值通过不等于自然舞蹈。当前不提供通用全身 IK、骨长编辑、自由裁剪或自由改变音乐/场景时长；不开放云保存、D1 写入或其他业务云写服务；不把未经许可与独立舞蹈审核的素材标为可教学内容。

原真实动作/Avatar/许可、教师与具名设备、生产身份/事务、原工程契约及正式教学 MP4 仍独立验收，M0–M3 保持原门槛。手动编辑质量和本机可靠性通过不等于真实教学或有限发布已通过。

验证优先本地与 mock，公网只执行必要的有界单轮；沿用服务端原生限频。完成阶段须将源码和最终实际验证文档提交 push，再同步授权 Cloudflare 预览并核对远端提交与实际运行版本。详细基础规则见 [手 K 设计](MANUAL_KEYFRAMES.md)、[场景备份](SCENE_BACKUPS.md) 和 [本机工作台清单](PRE_AI_CHECKLIST.md)。
