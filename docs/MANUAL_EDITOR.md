# 经典手动编辑器的当前范围

2026-10-08 用户明确调整当前开发顺序：AI 暂不接入，先将工作台完善成经典手动编辑器。当前优先提高本机摆姿、关键帧编辑和播放效率，完善音乐处理与作品保护；原工程 ZIP 的获取和生产契约集成不阻塞这些已授权的本机功能。

沿用单个原创实体人体及其 25 关节骨架、已确认的 CountMap、权威 Take、稀疏手 K 轨与不可变基底。操作、烘焙、音频解码与场景保存继续在浏览器完成，不调用模型或业务云写接口。`preview-1` 保持自身明确的预览契约；取得原包后仍须单独核对原指令、生成器和迁移，不据此声明原 2.1.0 兼容。

version 11 的经典手动编辑器、原创实体人体和新编辑关节包络已实现并上线。[功能源码](https://github.com/DFerryman/ChoreographyStudio/commit/e02b76bab054120b31314622cf416d752e847b6f)已 push 到 `main`，Cloudflare 运行版本为 `f245eba5-7cda-4950-bda7-f0cae576368b`。161 项本地基础检查、4 项新增约束交互和 20 项既有相关交互通过；本轮 CI、公网检查及实际运行证据分别见 [验证记录](VERIFICATION.md) 和 [部署记录](DEPLOYMENT.md)。version 10 的完整场景包、缺失原音乐恢复、显式 K 移动/复制、模态焦点与失败修正继续保留为历史基线。

## 极简界面与入口层级

用户进一步要求极简、清晰、有品质感的现代界面：只保留少量必要按钮，层级一眼可见。舞台是视觉中心，播放、当前帧/目标轨与显式写 K 是常用工作流；次要能力按需展开。用空间、字号、对齐和主次按钮表达层级，减少重复说明与装饰，不让新增功能变成常驻按钮堆积。

| 入口层级 | 本轮安排 |
| --- | --- |
| 常驻 | 舞台与选择/旋转/整体移动、播放与时间定位、当前编辑目标、显式写 K、关键保存状态 |
| 跟随上下文 | 对应选中关节或 Root 的数值编辑、当前轨 K 状态和必要禁用说明；原稿/候选/镜像状态及草稿处理保持清楚 |
| 按需展开 | 姿态复制/粘贴、删除与重置、显式键时刻转移、相机高级选项、坐标详情、备份与恢复等次要操作 |

折叠只改变显示层级，不改变动作、CountMap、历史、确认或资源保护，也不移除原有能力。保存失败、缺失原音乐、未写草稿、作用范围与冲突不能藏在折叠区域中；原有安全确认和取消入口仍需可见、可用。桌面与手机保留明确标签和键盘访问；展开入口至少 44px 高，手机主要编辑操作保持触控尺寸，320px 页面不产生横向溢出。展开后的控件继续使用既有操作规则。

参考官方编辑器的时间线和上下文参数组织：[Ableton Arrangement View](https://www.ableton.com/en/live-manual/12/arrangement-view/) 将播放控制与轨道/自动化显示控制分层；[DaVinci Resolve Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit/) 以选中对象的 inspector 和按需打开的关键帧/曲线编辑呈现参数；[Blender Timeline](https://docs.blender.org/manual/en/latest/editors/timeline.html) 以当前帧、关键帧和播放控制组织动画时间操作。本项目的三层入口是结合用户要求作出的设计决定，这些参考不扩大音乐/时长、曲线、自由剪辑或自动写 K 的范围。

当前默认关闭的入口包括「姿态复用」「更多编辑操作」「键盘快捷键」「移动与复制关键帧」，以及「相机选项」「舞台信息」「播放选项」「关节信息」「场景备份」；「K 完整姿态」位于属性栏帧导航下方。

后续每个新增功能先确定常驻、上下文或展开入口及默认状态，再实现；验收必须检查新手的常用流程是否依然清楚，以及折叠后原有功能、错误与保护是否可达。不能因为实现完成就将全部操作永久摆在首屏。

## version 11：快捷键与音乐处理

舞台快捷键复用现有按钮和编辑保护，不建立第二套写帧或历史规则。页面没有对话框且焦点不在交互控件时可使用：

| 快捷键 | 操作契约 |
| --- | --- |
| `←` / `→` | 按 30 fps 前后移动一帧；限制在合法首末帧，末帧仍对应原动作精确结束时刻；先处理未写草稿 |
| `Space` | 播放/暂停，沿用实际音频时钟与现有草稿、缺音频及观看状态保护 |
| `K` | 显式写当前关节旋转 K；整体移动工具下写 Root 位移 K。只操作对应轨，不隐式写完整姿态 |
| `Delete` | 删除当前关节的本帧显式 K；整体移动工具下仅删除 Root 本帧键。其他轨保持，无目标键不产生版本或历史 |
| `Ctrl` / `Cmd` + `Z` | 撤销，沿用共享场景历史与未写草稿保护 |
| `Ctrl` / `Cmd` + `Shift` + `Z`；`Ctrl` + `Y` | 重做，沿用相同历史和保护 |

输入框、数值/范围控件、下拉框、按钮、链接、可编辑文本及其他交互控件保留自身键盘行为。输入法组合、已处理事件和顶层模态不触发舞台操作。左右步帧可响应按键重复，播放、写 K、删除与历史动作不因长按重复提交。K/Delete 遵守暂停、原稿、未镜像和可编辑轨边界；只读末端不能写旋转 K，候选不隐式采用。草稿确认仍固定目标轨/关节/帧，取消不产生额外提交。

音乐读取与解码须可取消：关闭设置、取消、改用原创示例或开始新的读取时，先前异步结果失效。旧文件的读取、解码、错误及结束回调不能回写新对话框、覆盖新文件或改变当前作品；解码资源在结束、取消或页面卸载时清理。确认前仅更新音乐设置草稿，已有权威动画、CountMap、原音频和历史保持。

重新打开当前场景的音乐设置，应从已确认 CountMap 恢复第一数拍、八拍起点、数拍关系、BPM 和八拍数量。起点从 `sourceOffsetSeconds - firstCountSourceSeconds` 与每八拍时长恢复，界面使用从 1 开始的八拍编号；关闭重开不能把已有非零选段悄然改成第一八拍。用户显式确认音乐/数拍变更仍走原有提示和重建流程，不把旧 K 自动解释到新时间范围。

## 原创人体与关节活动限制

舞台使用原创程序化实体成人 mannequin：头颈、胸腹、骨盆、四肢、手掌和足部沿原 25 关节层级运动，中性灰白表面与小节点辅助共同显示姿态。模型不是 UE 官方资产、扫描真人或已许可的生产 Avatar。实体不进入节点拾取目标，原关节中心、父子关系、骨长、求值、相机和操作环保持原规则。

数值、滑条、3D 旋转环、发生变化的草稿旋转和新写旋转 K 共用同一四元数活动包络。下表是原预览骨架的保守编辑范围，单位为度，采用相对父骨骼的 intrinsic XYZ 表示；它不是临床关节活动度或对个人身体能力的判断。

| 关节 | X | Y | Z | 组合限制 |
| --- | --- | --- | --- | --- |
| Hips／整体朝向 | −180～180 | −180～180 | −180～180 | 不作局部解剖限位 |
| Spine／腰椎 | −20～35 | −25～25 | −25～25 | Y 轴 twist；swing ≤40 |
| Chest／胸椎 | −20～35 | −30～30 | −25～25 | Y 轴 twist；swing ≤40 |
| Neck／颈部 | −25～35 | −45～45 | −25～25 | Y 轴 twist；swing ≤40 |
| Head／头部 | −20～25 | −25～25 | −20～20 | Y 轴 twist；swing ≤30 |
| LeftShoulder／左锁骨 | −20～20 | −20～20 | −10～30 | Y 轴 twist；swing ≤35 |
| RightShoulder／右锁骨 | −20～20 | −20～20 | −30～10 | Y 轴 twist；swing ≤35 |
| LeftUpperArm／左肩 | −120～45 | −65～65 | −15～150 | Y 轴 twist；swing ≤150 |
| RightUpperArm／右肩 | −120～45 | −65～65 | −150～15 | Y 轴 twist；swing ≤150 |
| 左右 ForeArm／肘 | −145～0 | −8～8 | −5～5 | X 主屈曲；次级 Y/Z swing 为椭圆包络 |
| 左右 Hand／腕 | −60～60 | −15～15 | −25～25 | Y 轴 twist；swing ≤65 |
| LeftUpperLeg／左髋 | −110～25 | −35～35 | −20～45 | Y 轴 twist；swing ≤110 |
| RightUpperLeg／右髋 | −110～25 | −35～35 | −45～20 | Y 轴 twist；swing ≤110 |
| 左右 LowerLeg／膝 | 0～145 | −4～4 | −3～3 | X 主屈曲；次级 Y/Z swing 为椭圆包络 |
| LeftFoot／左踝 | −20～40 | −12～12 | −15～25 | Y 轴 twist；swing ≤45 |
| RightFoot／右踝 | −20～40 | −12～12 | −25～15 | Y 轴 twist；swing ≤45 |
| 左右指尖、脚尖、脚跟 | 只读 | 只读 | 只读 | 保留原末端旋转，不创建可编辑轨 |

球形关节的四元数 Y 轴 twist 取表中的 Y 范围，swing 指离开纵向静止轴的总摆角；三个 Euler 数值各自合法，组合仍可能超限。肘和膝分解后的次级 swing 角分量分别满足 `(Y/8)² + (Z/5)² ≤1` 与 `(Y/4)² + (Z/3)² ≤1`，不是两个可以同时取满的独立范围。四元数 X twist 内部允许肘 −146～1、膝 −1～146，以容纳微小的次级轴组合；表中 Euler 主屈曲边界仍严格。组合超限时沿向中立姿态的最短 SLERP 弧缩回合法包络，保存的仍是规范化 XYZW 四元数。左右肘都向 −X 屈曲，左右膝都向 +X 屈曲；左肩/髋外展为 +Z，右侧为 −Z，不随观看镜像翻转数据。

旧作品在加载、采样、播放、保存、导入、删除、键转移和撤销/重做中保持权威数据，不套新表自动修复，也不在重开时重烘焙。旧超限旋转显示原值及提示；编辑或写「K 当前关节」只约束该关节，编辑 Root／写「K 位移」不重写其他旋转。「K 完整姿态」明确对本帧 19 个可编辑旋转应用限制后提交，6 个末端保留。复制不修正源姿态，粘贴形成新草稿时对发生变化的可编辑旋转应用限制，仍须显式 K。骨长、CountMap、不可变基底与原场景格式保持。

限位检查针对新编辑与显式写键，不保证相邻 K 的整个 SLERP 区间始终满足该包络。当前没有 IK、脚锁、穿地/自身碰撞检测、分段质量/质心、重力或动力预览；路线与退出条件见 [真实编舞体验评估](REALISM_PLAN.md)。这些后续能力须保持作者意图和原稿，修正先作为可取消草稿或明确采用的新 Take，不在播放或拖动时间线时自动改数据。

## 验收与持续开发优先级

本轮验收范围包括快捷键操作、输入/模态隔离、草稿取消与目标固定、单轨边界、首末帧、按键重复、撤销/重做，以及音乐读取取消/旧结果隔离和已有非零八拍起点恢复。检查取消或失败时原作品、音频、CountMap、正式轨及历史保持；成功编辑仍可本机保存、重开和完整备份。界面分层须验证默认常用路径、次要功能展开、错误/保存状态与保护可达性；相关桌面/手机控件、既有按钮和舞台手势不能退化。v11 的已运行结果及 CI/公网证据见 [VERIFICATION.md](VERIFICATION.md)，已发布运行版本见 [DEPLOYMENT.md](DEPLOYMENT.md)；保留首轮失败和修正，不以旧版本证据替代新范围。

后续手动编辑继续优先解决可复现的编辑负担、播放/音频错误与本机作品保护，每一阶段写清具体行为和退出条件再验证。有限 IK、接触诊断和物理辅助是 [REALISM_PLAN.md](REALISM_PLAN.md) 中尚未实现的后续阶段，须另按退出条件开发与验证；当前不提供通用 IK、骨长编辑、自由裁剪或自由改变音乐/场景时长；不开放云保存、D1 写入或其他业务云写服务；不把未经许可与独立舞蹈审核的素材标为可教学内容。

原真实动作/Avatar/许可、教师与具名设备、生产身份/事务、原工程契约及正式教学 MP4 仍独立验收，M0–M3 保持原门槛。手动编辑质量和本机可靠性通过不等于真实教学或有限发布已通过。

验证优先本地与 mock，公网只执行必要的有界单轮；沿用服务端原生限频。完成阶段须将源码和最终实际验证文档提交 push，再同步授权 Cloudflare 预览并核对远端提交与实际运行版本。详细基础规则见 [手 K 设计](MANUAL_KEYFRAMES.md)、[场景备份](SCENE_BACKUPS.md) 和 [本机工作台清单](PRE_AI_CHECKLIST.md)。
